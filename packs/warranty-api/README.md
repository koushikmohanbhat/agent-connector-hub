# warranty-api

Generated from `warranty.yaml` by `hub generate openapi`.

- `getWarranty` (GET /warranties/{serial})
- `listWarrantyClaims` (GET /warranties/{serial}/claims)
- `createWarrantyClaim` (POST /warranties/{serial}/claims)

Set `WARRANTY_API_URL` to the API's base URL and `WARRANTY_IDENTITY` to how the hub should authenticate.
